# Carthagent 1.1.0-beta.6

## Quests and navigation

- A simpler quest board with clearer next actions and a separate **Completed (N)** view for the current daily slate.
- Completed quest details stay visible until you leave them.
- Editable evidence summaries, preserved drafts, clearer submission status, and explicit same-ID recovery for interrupted submissions.
- A compact Voyages rail with coins, Quests, Shop, Character, and Coding. Friends remains marked WIP.
- Empty project groups are hidden by default and available through **More → Show empty groups**.

## Native folder picker

- One current-location line and search by default.
- Path entry and New folder appear on demand; Escape cancels editing before closing.
- A visible selection marker and an explicit **Select folder** action.
- Compact layouts checked at 110×36, 80×24, and 60×20.

## Visual polish

- Native character and shop artwork with item previews.
- The original colored Ship / Lite / Plan / Build appearance is retained.
- Searchable command help.

## Beta scope

Daily quests award no coins or XP; verified Ship deliveries provide rewards.
Purchases and customization remain explicit confirmation actions.

Historical completed-run selection and recovery of the previously lost profile
remain outstanding. Live oversized-evidence submission, a newly forced mid-upload
termination, payment completion/explicit continuation, and the entire earlier
44-item acceptance checklist are not recertified by this UX release.

See [native UX acceptance evidence](native-ux-acceptance-2026-11-03.md) for the
recorded checks and limitations. This prerelease targets npm's `next` channel.
