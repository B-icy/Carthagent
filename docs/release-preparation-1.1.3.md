# Production release 1.1.3 runtime promotion

Release 1.1.3 promotes the complete v21 native patch, SHA-256
`9a73eb1ded4d9914a554640226949d53caca986ef8b846ef8592fe75a9a1bf92`, to the
published runtime. It carries every v20 sidebar fix plus the v21 polish
described in [staged-native-polish-v21.md](staged-native-polish-v21.md).

The build recipe, prebuild workflow, resolver pin and packaged
`lib/opencode/runtime-release.json` agree on that patch. The manifest is the
unchanged candidate generated by the five-platform prebuild of the reviewed
preparation commit. Upstream revision, lockfile, test budgets and generator
revision are unchanged. The immutable v15 to v20 patch comparisons remain
enforced.

The build recipe keeps its documented Intel macOS Rename-test waiver. Local
acceptance of a linux-arm64 build is recorded in the v21 document. It is not
pixel-level visual approval.
