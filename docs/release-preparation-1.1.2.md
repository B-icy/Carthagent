# Production release 1.1.2 runtime promotion

Release 1.1.2 promotes the complete v18 native patch, SHA-256
`636e01c3da517c64a5f90fb1ea6a682a25fbcb2b63372a8fd2c32ec11fe706dd`, to the
published runtime. It includes the reviewed question-form and first-use
changes; its only source delta from v17 is seven label expectations in two tests.

The build recipe, prebuild workflow, resolver pin and packaged
`lib/opencode/runtime-release.json` agree on that patch. The manifest is the
unchanged candidate generated by the five-platform prebuild of the reviewed
preparation commit. Upstream revision, lockfile, test budgets and generator
revision are unchanged. The immutable v15/v16/v17/v18 patch comparisons remain
enforced.

The build recipe keeps its documented Intel macOS Rename-test waiver. Local
candidate acceptance covered verified Ship delivery and typing while the optional
review notice is visible. It is not pixel-level visual approval.
